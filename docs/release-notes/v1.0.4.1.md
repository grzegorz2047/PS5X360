## PS5X360Reloaded v1.0.4.1

A hotfix for v1.0.4, built from source the same way. The home screen shows `PS5X360Reloaded v1.0.4.1`. It is installed and updated like v1.0.4 (`PPSA83600.ffpkg`, `.ffpfsc` or `.zip`; the whole `PPSA83600` folder, not `eboot.bin` alone). Its `contentVersion` is `01.004.001`, so the console sees v1.0.4 as an older install.

**How to read the status tags below:**
- `[console]`: confirmed on PS5 on a test build; the build is named.
- `[host tests]`: verified by tests on a computer (`tools/check-*`, run in CI), not confirmed on the console.

### Fixes
- **Battlefield 3 (`45410950`) no longer crashes after about 14 minutes of online play** (fixes 80, 82):
  - Before: with the Xenia online service connected, the game made about 15 enumerators a second, each with a buffer of about 21 KiB, and none was ever freed. The emulator's part of the guest memory (256 MiB) filled up, and the game read through a null pointer.
  - `ObDereferenceObject` now finds the emulator's enumerators by their address, so the reference the game takes is given back and closing one frees it (fix 80). The buffer the game attaches to each enumerator is freed with it, as the console's system software does (fix 82). The bug is in the 1.0.2 code itself; v1.0.3 and v1.0.4 have it.
  - `[console, 1.0.4.1 test build with fixes 80 and 82: 29 minutes of play at 30 FPS with the guest heap flat at 1 MiB instead of climbing about 0.4 MiB a second; host tests]`
- **Red Dead Redemption (`5454082B`) no longer drops back to the launcher after the storage device is chosen** (fix 85):
  - The game restarts itself there (`XamLoaderLaunchTitle` with an empty name, the title's own executable); the emulator took that for "exit to the dashboard" and the restart opened the launcher. It now starts the same game again.
  - `[console, 1.0.4.1 test build with fix 85: the game came back after the restart; host tests]`

### Tested on the console
`1.0.4_candidate_36`, the code of this release: Battlefield 3, Red Dead Redemption, Call of Duty: Modern Warfare 2, Fable II, Tekken Tag Tournament 2 and Ninja Gaiden II started, played and returned to the launcher without a crash or hang.

### Known limitations
- Everything listed for v1.0.4 still applies.
- Tekken Tag Tournament 2 (`4E4D0859`): some costume colours are wrong (issue #14); not fixed in this hotfix, under investigation.
  Workaround: in the game's settings, set "Image readback by the game" to "Full (slow)" before starting it. The colours are then right, at a cost of a few FPS (about 49 instead of 57-60 on our test build) `[console, 1.0.5-work-fix83 with the full readback set before launch: colours correct]`.
